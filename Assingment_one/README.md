

# MapleFreight Delivery Delay Prediction

## Problem
Predict whether a shipment will miss its promised delivery window and alert dispatch through Slack while intervention may still be possible.

## Dataset
Place `maplefreight_delivery_delay_dataset.csv` beside the notebook. The file contains shipment, route, carrier and delivery outcome information. Target: `delivered_late` (1 = late).

## How to run
1. Install Python 3.10+ and Jupyter.
2. Create a virtual environment if desired.
3. Install dependencies: `pip install -r requirements.txt`
4. Open `MapleFreight_Delivery_Delay_Prediction_your_id.ipynb`.
5. Run all cells from top to bottom.
6. Review the actual metrics and update this README with the values generated by your run.

## Leakage prevention
`actual_transit_hours` is excluded because it is known only after delivery. `shipment_id` is also excluded from model features. The preprocessing pipeline is fitted on training data only. Threshold selection uses validation data; the test set is reserved for final evaluation.

## Slack alert setup
1. Create or choose a Slack workspace and create `#dispatch-alerts`.
2. Create a Slack app and enable Incoming Webhooks.
3. Add a webhook to `#dispatch-alerts`.
4. Create a local `.env` file beside the notebook with:
   `SLACK_WEBHOOK_URL=https://hooks.slack.com/services/REPLACE/WITH/YOUR/OWN`
5. Replace the example value with your private webhook URL. Never commit `.env`, paste the real URL into notebook cells, or print it.
6. Run the Slack cell. If configured, it posts a summary and the top five risk scores.
7. Capture a screenshot of the real Slack message and save it as `screenshots/slack_alert.png`.
